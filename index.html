Come si muove l'ascensore?

Movimento dell'Ascensore

Aggiungere un numero relativo determina la direzione del movimento dell'ascensore:

+ ( + x )
➜ SALI (+)
Sommare un numero positivo fa Salire l'ascensore verso l'alto
+ ( - x )
➜ SCENDI (-)
Sommare un numero negativo fa Scendere l'ascensore verso il basso

Quale segno avrà il risultato?

Regola del segno finale in base ai segni dei due addendi:

Concordi +
( + ) + ( + )
Risultato POSITIVO (+)
Due numeri positivi danno sempre un numero positivo.
Concordi -
( - ) + ( - )
Risultato NEGATIVO (-)
Due numeri negativi danno sempre un numero negativo.
Discordi
( + ) + ( - ) / ( - ) + ( + )
Vince il più grande!
Il segno è quello del numero più lontano dallo zero (valore assoluto maggiore).
